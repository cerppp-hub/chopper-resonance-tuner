## Snapmaker U1 adaptation

> The `snapmaker-u1` branch packages Chopper Resonance Tuner for the stock
> Snapmaker U1 through Bespok3d. It supports the TMC2240 CoreXY X/Y path, uses
> the stock `e0_lis2dw` accelerometer, corrects the driver clock to 12.5 MHz,
> and replaces the upstream runtime dependencies with a standard-library
> report generator.
>
> Do not run upstream `install.sh` on a U1. See the
> [Snapmaker U1 installation and safety guide](docs/SNAPMAKER_U1.md).
