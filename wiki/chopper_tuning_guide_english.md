# Snapmaker U1 chopper tuning guide

The generic upstream procedure has been replaced on this branch by the U1
CoreXY workflow. It covers motor isolation, firmware 1.6+/2.0 accelerometer
naming, static TMC values, optional runtime overrides, 200- and 400-step
motors, safe commands, and
recovery.

Read the [Snapmaker U1 installation and safety guide](/docs/SNAPMAKER_U1.md)
before running `CHOPPER_TUNE`.
